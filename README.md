# AWS Resource Tracker 🛰️

A simple Bash script to automatically track and log AWS cloud resources such as S3 buckets, IAM users, and EC2 instances.

## 📋 Features
- ✅ Lists all available **S3 buckets**
- ✅ Lists all **IAM users**
- ✅ Lists all **EC2 instances**
- ✅ Logs all output to a **timestamped log file**
- ✅ Uses **AWS CLI** (assumes you're already authenticated)
- ✅ Can be scheduled with **cron** for daily/regular audits

## 📁 Folder Structure
```
aws-resource-tracker/
│
├── aws_resource_tracker.sh         # Main script
├── logs/                           # Log files generated by the script
└── README.md                       # Project documentation
```

---

## ⚙️ Prerequisites
Before running the script, ensure the following:

- **AWS CLI** is installed and configured:
    ```bash
    aws configure
    ```

- Appropriate **permissions** to run AWS commands like `s3`, `iam`, and `ec2` are set up.

- A **Bash shell environment** (Linux, macOS, or Windows Subsystem for Linux (WSL)).

## 🛠️ Usage

### Running the Script Manually

1. First, make the script executable:
    ```bash
    chmod +x aws_resource_tracker.sh
    ```

2. Then run the script:
    ```bash
    ./aws_resource_tracker.sh
    ```

### Sample Output Log

The script generates logs in the `logs/` directory with a timestamped filename. For example:
```
logs/aws_resource_tracker_2025-04-14_22-40.log
```
Each run will create its own log file.

---

## ⏰ Automate with Cron (Optional)

You can automate the script to run at regular intervals using **cron**. For instance, to run the script every day at **10:40 PM**, do the following:

1. Open your crontab file:
    ```bash
    crontab -e
    ```

2. Add this line to schedule the script:
    ```bash
    40 22 * * * /mnt/c/het_projects/shell_scripting/aws_resource_tracker.sh >> /mnt/c/het_projects/shell_scripting/aws-resource-tracker/logs/cron_output.log 2>&1
    ```

This will ensure the script runs at the specified time, logging its output to `cron_output.log`.
